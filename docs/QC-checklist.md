# QC Checklist — ก่อนอัปโหลดตอนใหม่ (ช่องปุยฝัน / Puifun)

> โครงเช็กลิสต์เริ่มต้น — ปรับได้ตามที่เจอปัญหาจริงระหว่างผลิต

## 1. ความปลอดภัยของเด็ก / นโยบายแพลตฟอร์ม
- [ ] เนื้อหาเหมาะกับเด็กเล็ก (ไม่มีความรุนแรง / คำหยาบ / เนื้อหาชวนกลัวเกินวัย)
- [ ] ทำเครื่องหมาย **Made for Kids** ในหน้าอัปโหลด YouTube
- [ ] ไม่มีลิงก์ภายนอก / call-to-action ไปเว็บที่ไม่เหมาะกับเด็ก
- [ ] Thumbnail ไม่ clickbait และไม่มีภาพชวนตกใจ

## 2. ลิขสิทธิ์ / ที่มา
- [ ] ทุก asset ที่ AI สร้าง มีบันทึกใน `rights_log` (tool / prompt / license note)
- [ ] เพลง / เสียงประกอบ ใช้แหล่งที่มี license ชัดเจน (มีลิงก์แนบใน description ถ้าจำเป็น)
- [ ] ตรวจว่าไม่มีชื่อคาแรกเตอร์ / เพลง / ยี่ห้อ ที่ชนกับแบรนด์อื่น

## 3. คุณภาพเสียง
- [ ] Loudness ~ -14 LUFS (สำหรับ YouTube)
- [ ] ไม่มีคลิป (clipping) / เสียง pop / ลมเข้าไมค์
- [ ] เสียงพากย์ชัด แยกออกจากเพลงประกอบ

## 4. คุณภาพภาพ / วิดีโอ
- [ ] Aspect ratio 16:9 (หรือ 9:16 สำหรับ Shorts) และความละเอียดถูกต้อง
- [ ] คาแรกเตอร์ตรงกับ style guide (สี, สัดส่วน, ท่าทาง)
- [ ] ไม่มีเฟรมกระตุก / เฟรมดำหลุด / ตัวหนังสือสะกดผิด
- [ ] Signature "ดาวเรืองแสงปิดท้ายนิทาน" ครบถ้วนตามธีมช่อง

## 5. Metadata
- [ ] ชื่อคลิป (title) มีคีย์เวิร์ดหลัก + ชื่อแบรนด์ "ปุยฝัน"
- [ ] Description มีสรุปเรื่อง + หมวดหมู่ (นิทาน / เพลง / ตลก)
- [ ] Tag / หมวดหมู่ / ภาษา = ไทย
- [ ] Thumbnail ตรงกับเนื้อหาจริง

## 6. ก่อนกดอัปโหลด
- [ ] Preview ดูจบทั้งคลิปอย่างน้อย 1 รอบ
- [ ] มีคนช่วย QC อีกคน (ถ้าเป็นไปได้)
- [ ] อัปเดต `PROGRESS.md` ว่าตอนนี้อยู่สถานะไหน
