## หมายเหตุการผลิต

- โมทีฟ 3 โน้ต "ปุย~ฝัน~ฝัน~" ในวงเล็บคือ hook หลักของแบรนด์ — ต้องขึ้นซ้ำใน Chorus ทุกครั้งเพื่อสร้าง brand recall ให้เพลงถัดไปในอนาคตใช้โมทีฟเดียวกันได้
- แนะนำ generate 3–4 เวอร์ชันจาก prompt เดียวกัน แล้วเลือกเวอร์ชันที่จังหวะ "ปุย~ฝัน~ฝัน~" ฟังติดหูที่สุด — เวอร์ชันที่เลือกจะกลายเป็น "official melody" ของแบรนด์ตลอดไป
- อย่าลืมบันทึกลง Rights Log ทันทีหลัง export: เครื่องมือ = Suno, แผนที่ใช้ตอนสร้าง, วันที่, prompt ที่ใช้จริง
